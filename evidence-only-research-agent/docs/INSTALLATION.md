# Installation

Requires Python 3.11 or newer. The commands below were run on Python 3.12.10 on Windows. On that machine `python` was not on `PATH`, so the examples use `py -3`. Use `python` or `python3` where that is the interpreter.

From this directory:

```bash
py -3 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
py -3 examples/build_sample_pdfs.py
py -3 cli.py index ./examples/documents
py -3 -m pytest
```

On Unix-like shells the virtual environment interpreter is `.venv/bin/python`.

`requirements.txt` pins the versions that passed in a clean virtual environment:

- `pydantic==2.14.1`
- `pymupdf==1.26.5`
- `numpy==2.3.0`
- `pytest==8.4.0`

No API key is required for indexing, asking, or tests. The default generation provider is `extractive` and the default embedding provider is `local`.

Run pytest from this directory so it uses `pytest.ini`. Running it from a parent folder can collect unrelated projects.

The sample PDFs are generated by `examples/build_sample_pdfs.py` into `examples/documents`. The text and Markdown files are already in that folder. Regenerating the PDFs overwrites those three study files and `scans/empty_scan.pdf`.

The local index is written to `data/index` and is gitignored.
