# Cancellation Policy

## Notice

The subscription cancellation policy requires fourteen days written notice. Subscribers must give fourteen days written notice before a cancellation takes effect. Notice is counted from the day the billing desk receives the written message. A spoken message does not start the clock.

The subscription cancellation policy requires fourteen days written notice, which differs from a product refund.

## Billing

When a subscriber cancels, the current billing cycle is not returned as cash. Access continues until the paid cycle ends. A cancellation is not a product return.

## How to cancel

Send the account id from the billing page to the billing desk. The desk replies with a confirmation the next morning. Keep that confirmation with the account records. A cancellation can be withdrawn before it takes effect by sending a second written message.
